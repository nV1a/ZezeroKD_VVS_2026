## [ДЗ №1: Варианты калькулятора на Python](./HW1)

* **[calc1.py](./HW1/calc1.py)** - Самый простой калькулятор, написанный «в лоб» с помощью обычных условий.
* **[calc2.py](./HW1/calc2.py)** - Тот же калькулятор, но теперь каждое математическое действие вынесено в отдельную функцию.
* **[calc3.py](./HW1/calc3.py)** - Калькулятор с циклом while. Он запоминает предыдущий результат и позволяет продолжать вычисления дальше, пока сам не решишь выйти.
* **[calc4.py](./HW1/calc4.py)** - Практическая задачка с использованием классов. Это калькулятор для условного производителя соков: он считает чистую прибыль и следит, чтобы расход сахара на объем не превышал норму (80 грамм).

## [ДЗ №4: Анализ данных пассажиров Титаника (Pandas и NumPy)](./HW4)
Основы анализа данных с помощью библиотек Pandas и NumPy. Для этого использовался датасет с информацией о пассажирах Титаника.

* **[titanic(vvs).ipynb](./HW4/titanic(vvs).ipynb)** — Jupyter Notebook с кодом. В нем загружал данные, искал и заполнял пропущенные значения (например, заменял пустой возраст медианой), фильтровал пассажиров по условиям и считал статистику выживаемости с помощью массивов NumPy. В конце файла написаны выводы.
* **[titanic_processed.csv](./HW4/titanic_processed.csv)** — Очищенная таблица данных, из которой удалены проблемные строки и столбцы (например, столбец с каютами, где не хватало почти 80% данных).
* **[titanic_statistics.csv](./HW4/titanic_statistics.csv)** — Сводная таблица, где данные сгруппированы по классу билета и полу пассажира с подсчетом процента выживших.
