# ZezeroKD_VVS_2026

Домашние задания по курсу «Введение в специальность». Все работы написаны на Python 3.

## [ДЗ №1: Варианты калькулятора на Python](./HW1)

* **[calc1.py](./HW1/calc1.py)** - Самый простой калькулятор, написанный «в лоб» с помощью обычных условий.
* **[calc2.py](./HW1/calc2.py)** - Тот же калькулятор, но теперь каждое математическое действие вынесено в отдельную функцию.
* **[calc3.py](./HW1/calc3.py)** - Калькулятор с циклом while. Он запоминает предыдущий результат и позволяет продолжать вычисления дальше, пока сам не решишь выйти.
* **[calc4.py](./HW1/calc4.py)** - Практическая задачка с использованием классов. Это калькулятор для условного производителя соков: он считает чистую прибыль и следит, чтобы расход сахара на объем не превышал норму (80 грамм).

Запуск: `python3 HW1/calc1.py` (и так же для остальных файлов).

## [ДЗ №2: Обучающая игра по методам строк](./HW2)
Разбор работы со строками в Python.

* **[game1.py](./HW2/game1.py)** - Интерактивная программа-справочник. Она просит ввести текст и позволяет практиковаться с ним на разных уровнях:
  * **Уровень 1:** Изменение регистра букв (upper, lower, capitalize).
  * **Уровень 2:** Поиск слов, их замена и подсчет (find, replace, count).
  * **Уровень 3:** Разделение текста и склейка обратно (split, join).
  * **Уровень 4:** Проверка на числа/буквы и обрезка лишних пробелов по краям (isdigit, isalpha, strip).
  * **Уровень 5:** Сборный уровень. Там есть «песочница» со всеми 12 методами, а также функция автоматической очистки «грязного» текста (убирает точки, точки с запятой, лишние пробелы и делает первую букву заглавной).

Запуск: `python3 HW2/game1.py`

## [ДЗ №3: Консольная игра-лабиринт](./HW3)
Работа со списками: игра, где игрок ходит по матрице N×N.

* **[game.py](./HW3/game.py)** - Лабиринт из комнат: пустые, сундуки, монстры, ловушки, ключи, порталы, комната зачарования и выход. Игрок собирает и выбрасывает предметы, сортирует и переворачивает инвентарь, ищет предметы, копирует списки и пользуется зельями и подсказками. Сундуки бывают заперты, у каждого свой ключ. Нож убивает монстра за 5 ударов, а зачарованный за 3 и без ответного урона. Лабиринт генерируется случайно, но всегда проходим. Размер выбирается при запуске, ходить можно клавишами W, A, S, D.

Запуск: `python3 HW3/game.py`

## [ДЗ №4: Анализ данных пассажиров Титаника (Pandas и NumPy)](./HW4)
Основы анализа данных с помощью библиотек Pandas и NumPy. Для этого использовался датасет с информацией о пассажирах Титаника.

* **[titanic(vvs).ipynb](./HW4/titanic(vvs).ipynb)** - Jupyter Notebook с кодом. В нем загружал данные, искал и заполнял пропущенные значения (например, заменял пустой возраст медианой), фильтровал пассажиров по условиям и считал статистику выживаемости с помощью массивов NumPy. В конце файла написаны выводы.
* **[titanic_processed.csv](./HW4/titanic_processed.csv)** - Очищенная таблица данных, из которой удалены проблемные строки и столбцы (например, столбец с каютами, где не хватало почти 80% данных).
* **[titanic_statistics.csv](./HW4/titanic_statistics.csv)** - Сводная таблица, где данные сгруппированы по классу билета и полу пассажира с подсчетом процента выживших.

Ноутбук делался в Google Colab, открыть его можно там же или в Jupyter (нужны библиотеки `pandas` и `numpy`).

## [ДЗ №5: Оконные приложения (Qt и tkinter)](./HW5)
Графический интерфейс на двух библиотеках: в каждом приложении есть окно, надписи, поля ввода, кнопки, выбор параметров, вывод результатов, обработка событий, проверка данных и диалоговые окна.

* **[Qtforfilms.py](./HW5/Qtforfilms.py)** - «Фильм на вечер» на PyQt6. Каждый друг вводит имя и отмечает любимые жанры, а программа подбирает фильм, который устроит всех: меньше всего расстроит самого недовольного.
* **[barca_tracker.py](./HW5/barca_tracker.py)** - «Трекер матчей Барсы» на tkinter. Добавление матча (соперник, счёт, дата, дома или в гостях, турнир) с проверкой данных, список матчей и статистика побед, ничьих и поражений. Удаление матча с подтверждением.

Запуск:
```
pip3 install pyqt6
python3 HW5/Qtforfilms.py
python3 HW5/barca_tracker.py
```
`tkinter` входит в стандартную установку Python, отдельно ставить его не нужно.
